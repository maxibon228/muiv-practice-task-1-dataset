# Задание №1: Подготовка данных к работе

Этот репозиторий содержит решение задания №1
технологической (проектно-технологической) практики для студента
Сахарова Максима Геннадьевича (вариант 18 по первой букве фамилии «С»).

## Назначение проекта

Необходимо подготовить исходные данные к дальнейшему анализу и
визуализации.  Скрипт `dataset.py` загружает исходный файл
`dataset.csv` в глобальный DataFrame, а при запуске выводит
информацию о наборе данных в консоль и сохраняет её в файл
`report.txt`.  В отчёте приводятся типы данных, количество
пропущенных значений, базовая статистика для числовых колонок и
распределения по категориям для категориальных колонок.

## Используемый датасет

Датасет выбирается по таблице вариантов: для буквы «С»
соответствует вариант 18.  Файл `dataset.csv` содержит 150 строк и 9
колонок.  Индексная колонка `Unnamed: 0` техническая и не
используется в анализе.

### Колонки

* **platelets** — числовая (количество)
* **serum creatinine** — числовая (уровень креатинина)
* **serum sodium** — числовая (уровень натрия)
* **creatinine phosphokinase** — числовая (уровень фермента)
* **ejection fraction** — числовая (фракция выброса)
* **sex** — категориальная (0/1)
* **smoking** — категориальная (0/1)
* **death** — категориальная (0/1)

## Состав репозитория

* `dataset.csv` — исходный датасет варианта 18
* `dataset.py` — модуль загрузки и анализа данных
* `requirements.txt` — список зависимостей
* `README.md` — описание задания
* `report.txt` — файл отчёта, создаётся после запуска скрипта

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Запустите анализ данных:

   ```bash
   python dataset.py
   ```

   Скрипт выведет информацию о датасете в консоль и создаст файл
   `report.txt` в той же папке.

## Примечания

При импорте модуля `dataset` (например, `import dataset`) никаких
распечаток не производится; только создаётся глобальный объект
`df`, содержащий прочитанный датасет.
